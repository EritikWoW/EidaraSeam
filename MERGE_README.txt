EidaraSeam Subway Patch

Этот архив НЕ содержит тяжёлые ассеты метро.
Он содержит только готовый патч проекта, чтобы не упираться в лимит размера.

Как применить:
1. Возьми свой текущий проект EidaraSeam.
2. Распакуй содержимое subway.zip в КОРЕНЬ проекта так, чтобы появилась папка:
   res://subway/
3. Распакуй содержимое Godot-4-Overgrown-Subway-Demo-...zip в КОРЕНЬ проекта,
   чтобы появились папки:
   res://props/
   res://foliage/
   res://fps_controller/
   res://outside_walls/
   res://sound/
   res://menu/
   res://addons/
4. После этого распакуй ЭТОТ патч поверх проекта с заменой файлов.
5. Открой project.godot в Godot.
6. Подожди импорт .blend и ресурсов.
7. Запусти сцену.

Что делает патч:
- встраивает сцену метро как Metro
- оставляет твоего Player
- удаляет demo fps_controller из ассета
- добавляет Focus visual effect
- ставит Seam/BlockWall/Trigger прямо в сцену метро
- игрок стартует возле нужного места

Управление:
- WASD — движение
- Space — прыжок
- Q — Focus
- Esc — освободить мышь
